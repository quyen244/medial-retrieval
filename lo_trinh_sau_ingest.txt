LỘ TRÌNH SAU KHI INGEST XONG
============================

Chạy trong ~/medial-retrieval, venv đã kích hoạt:
    cd ~/medial-retrieval && source venv/bin/activate
Lệnh chạy lâu thì để trong tmux (tmux new -s <tên>; thoát: Ctrl+b rồi d; vào lại: tmux attach -t <tên>).


0. KIỂM TRA VÀ BACKUP
---------------------
python ~/ingest_status.py                        # ledger và Qdrant khớp số
nvidia-smi                                       # GPU trống
python -m scripts.qdrant_backup backup --collection medical_documents


1. TẮT vLLM: CHẠY CÁC BÀI THÍ NGHIỆM (200 câu đầu)
-------------------------------------------------
R="python -m src.rag.run_full_submission --collection medical_documents --limit 200 --pad-empty"
AUG=data/augment_v2_full/augmented.jsonl   # B' đủ 1200 câu, dùng chung cho thí nghiệm và bài cuối

# chạy thử 5 câu trước
python -m src.rag.run_full_submission --collection medical_documents --limit 5 --pad-empty \
  --augmented $AUG --checkpoint tmp/sub/smoke.jsonl --out tmp/sub/smoke.json

# TN1: A, B, B'
$R --checkpoint tmp/sub/A.jsonl --out tmp/sub/A.json
$R --augmented data/augment_B/augmented.jsonl --checkpoint tmp/sub/B.jsonl --out tmp/sub/B.json
$R --augmented $AUG --checkpoint tmp/sub/Bp.jsonl --out tmp/sub/Bp.json

# TN3 (tắt giữ chỗ), TN5 (quota căn bậc hai), TN2 (hybrid) - đều trên B'
$R --augmented $AUG --no-sub-rerank           --checkpoint tmp/sub/Bp_noslot.jsonl --out tmp/sub/Bp_noslot.json
$R --augmented $AUG --branch-quota sqrt       --checkpoint tmp/sub/Bp_sqrt.jsonl   --out tmp/sub/Bp_sqrt.json
$R --augmented $AUG --retriever qdrant-hybrid --checkpoint tmp/sub/Bp_hyb.jsonl    --out tmp/sub/Bp_hyb.json

Mỗi bài tự lưu kèm tmp/sub/<tên>_top50.jsonl, dùng cho TN4.


2. TN4: LẮP BÀI OFFLINE TỪ BÀI TỐT NHẤT (ví dụ B')
-------------------------------------------------
T=tmp/sub/Bp_top50.jsonl
BASE=tmp/sub/Bp.json
python -m scripts.assemble_submission check --top50 $T --base $BASE     # phải 200/200 khớp
python -m scripts.assemble_submission stats --top50 $T                  # xem điểm để chọn ngưỡng
python -m scripts.assemble_submission build v1 --k 10 --top50 $T --base $BASE --out tmp/sub/Bp_v1k10.json
python -m scripts.assemble_submission build v2 --tau-pct 30 --delta 0.5 --top50 $T --base $BASE --out tmp/sub/Bp_v2.json
python -m scripts.assemble_submission build v3 --per-doc 2 --tau-pct 30 --top50 $T --base $BASE --out tmp/sub/Bp_v3.json

Chọn --tau-pct và --delta sau khi xem kết quả stats; số trên chỉ là điểm bắt đầu.


3. SO SÁNH RỒI NỘP
------------------
python -m scripts.compose_submission compare --a tmp/sub/A.json \
  --b tmp/sub/B.json --b tmp/sub/Bp.json --b tmp/sub/Bp_noslot.json \
  --b tmp/sub/Bp_sqrt.json --b tmp/sub/Bp_hyb.json

Tối đa 10 bài/ngày. Bài nào chồng lấn trên 0.95 với bài đang dẫn thì bỏ qua.


4. DEV SET (chấm tay song song với các bước sau)
------------------------------------------------
python -m scripts.build_dev_set export --with-pipeline
# mở data/labeling/dev_set_template.tsv, điền cột human_score 0-3
python -m scripts.build_dev_set import
python -m scripts.build_dev_set status


5. BẬT vLLM: SINH NHÃN
----------------------
bash scripts/serve_vllm.sh                       # tmux riêng, mặc định GPU 0.6

python -m src.rag.labeling.run_generate --pilot  # CỔNG 1: soát data/labeling/sample_de_soat.json
                                                 #   tỉ lệ dài/ngắn ~66/34, keep rate >= 40%,
                                                 #   xem keep_rate theo ngôn ngữ ở dòng [b3]
python -m src.rag.labeling.run_judge --pilot     # CỔNG 2: soát data/labeling/sample_judged_de_soat.json

Trước khi chạy full: chỉnh candidate_search trong src/rag/labeling/config.py theo TN2
(hybrid thắng -> giữ "hybrid"; dense thắng -> đổi thành "dense").

python -m src.rag.labeling.run_generate          # chỉ khi cả hai cổng qua
python -m src.rag.labeling.run_judge

Trong lúc vLLM đang bật, augment đủ 1200 câu cho bài nộp cuối:
python -m src.rag.augment.run_augment --queries data/queries/real_queries.jsonl --out-dir data/augment_v2_full


6. TẮT vLLM: TRAIN RERANKER
---------------------------
python -m src.rag.labeling.build_train_set       # tạo data/labeling/train.jsonl + val.jsonl
python sft-reranker/main.py                      # lưu model vào ./models/medical-reranker


7. BÀI NỘP CUỐI (đủ 1200 câu)
-----------------------------
python -m src.rag.run_full_submission --collection medical_documents \
  --augmented data/augment_v2_full/augmented.jsonl \
  --reranker-model ./models/medical-reranker \
  --checkpoint tmp/sub/final.jsonl --out tmp/sub/final.json
# áp cách lắp thắng ở TN4, ví dụ:
python -m scripts.assemble_submission build v2 --tau-pct 30 --delta 0.5 \
  --top50 tmp/sub/final_top50.jsonl --base tmp/sub/final.json --out tmp/sub/final_v2.json
python -m scripts.build_dev_set eval --submission tmp/sub/final_v2.json


NÊN SO TRƯỚC KHI CHỐT
---------------------
Reranker đã fine-tune có thật tốt hơn bản gốc không: chạy cùng cấu hình trên 200 câu,
một bài có --reranker-model ./models/medical-reranker, một bài không, rồi so điểm
(và build_dev_set eval nếu dev set đã chấm).
